WAKANDA WARRIORS SOCCER TEAM WEBSITE



Project summary



The Wakanda Warriors soccer team website is a web application project designed to provide a central place where player, supporters, and visitors can find information about Wakanda Warriors soccer team.

The purpose of this project is to make team information easier to access and manage. Currently, information such as player detail, upcoming games schedules, and match results can be difficult to find when it is shared through different communication channels. This website aims to organize that information in one convenient location.

The website will allow visitors to learn about the team, view player profiles, check upcoming games, and review previous match result. It will also provide planned administrative features that will allow authorized team administrators to manage player information, schedules, and match results.

I selected this project because I enjoy soccer and wanted to develop a useful application connected to a real team. This project also gives me an opportunity to apply what I am learning in secure web application development.

The project will start with a simple website prototype and gradually develop into a more complete application. My development goals include creating user-friendly interface, implementing interactive features, and considering security requirements such as authentication, authorization, input validation, and protection against common web vulnerabilities.

INSTALLATION



To use this project efficiently, you need:

* windows 10 or Windows 11.
* A modern web browser such as Google Chrome, Microsoft Edge, or Firefox
* A text editor such as Visual Studio Code, Sublime Text, or Notepad
* Git if you want to clone the repository.

Installation steps



1. Clone the repository from GitHub:



git clone https://github.com/seydoubarro2011-bot/Wakanda\_Warriors\_Soccer\_Website.git



2\. Open the project folder:

cd Wakanda\_Warriors\_Soccer\_Website



3\. Open the <index.html> file in your web browser.

No additional packages or dependencies are required for the initial HTML, CSS and JavaScript prototype.



Getting Started



* Open the project folder
* Open index.html using your web browser
* use the navigation menu to explore the Home, Players, schedule, and Results sections
* Visit the players section to view player information
* Use the player search feature to find a player by name.



The current version is low-fidelity prototype. Additional features and security improvements will be developed as the project progresses.
